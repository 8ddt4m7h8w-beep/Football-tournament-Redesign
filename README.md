# FOOTBALL TOURNAMENT PWA

## Функции
- Матчи из заданного расписания, по 10 минут; ввод счёта с автосохранением.
- Таблица: сыграно, победы, ничьи, поражения, голы, разница и очки 3/1/0; сортировка очки → разница → забитые.
- Редактирование имён и названий, добавление и удаление команд/игроков.
- Бомбардиры с ручным счётчиком голов и сортировкой.
- Плей-офф после шести результатов: полуфиналы 1–4 и 2–3, матч за третье место, финал. При ничьей в плей-офф выбор победителя вручную.
- Резервная копия JSON (экспорт/импорт), экспорт турнирной таблицы CSV.
- PWA, офлайн-кеш, сохранение в локальном хранилище устройства.

## GitHub Pages (бесплатно)
1. Создайте GitHub репозиторий `football-tournament`.
2. Загрузите файлы проекта и папку `icons` в корень репозитория.
3. Откройте Settings → Pages.
4. Выберите Deploy from a branch, branch `main`, folder `/ (root)`, Save.
5. Откройте опубликованный HTTPS URL.

## Netlify
Можно импортировать репозиторий GitHub в Netlify либо загрузить папку проекта через Netlify Drop.

## Установка iPhone
1. Откройте сайт HTTPS в Safari.
2. Поделиться → На экран «Домой».
3. Включите «Открывать как веб-приложение» (если опция доступна) → Добавить.
4. Иконка появится на главном экране.

## Резервное копирование
Данные сохраняются в localStorage браузера на этом устройстве. Регулярно скачивайте JSON backup кнопкой ↗ и храните его в Files/iCloud. Восстановление производится кнопкой «Восстановить копию». CSV выгружает standings.
